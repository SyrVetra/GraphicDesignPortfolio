# images

Put your graphics in this folder, then point to them from `content.js`,
e.g. `art: "images/01-cover.jpg"`.

Suggested names (these match the examples already in `content.js`):

| File | Used for |
|------|----------|
| `01-thumb.jpg` | thumbnail on the rotating selector (~800×800px) |
| `01-cover.jpg` | large art on the project page (2000–3000px square) |
| `01-back.jpg`, `01-label.jpg`… | extra project images (any shape) |
| `portrait.jpg` | your photo in the About section (~1200×1500px) |

To upload on github.com: open this folder, then **Add file → Upload files**.
Keep file names lowercase with no spaces.
